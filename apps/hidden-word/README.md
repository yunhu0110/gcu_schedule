# HIDDEN WORD — 실시간 멀티플레이 웹앱

데블스 플랜 메인매치 분위기의 한국어 단어 추리 게임. 각자 스마트폰으로 접속해 실시간 플레이, PC 대형 대시보드는 선택.

## 기술 스택 (확정)
- **프론트**: React + TypeScript + **Vite** (이 디렉터리, `apps/hidden-word`)
- **백엔드**: **기존 gcu_schedule Supabase 재사용** — Postgres + RLS(히든워드 서버 보호) + Realtime(동기화) + RPC(점수/단계 서버 검증). 추가 과금 없음.
  - Firebase 미사용 이유: Cloud Functions가 Blaze(유료) 필요 → "무료 최우선" 원칙과 충돌. Supabase가 동일 요구(서버측 비밀/점수)를 무료로 충족.
- **환경변수**: `.env.local`에 `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` (anon 키만, 공개 안전). `service_role` 키 금지.

## 실행
```bash
cd apps/hidden-word
cp .env.example .env.local   # 값 채우기(기존 Supabase anon 재사용 가능)
npm install
npm run dev                  # http://localhost:5173
npm run build                # dist/
```

## 디자인
`design/stitch_word_design/` 시안 기준. 다크 퍼플 `#16141c` + 양피지 크림 + 골드 장식 + 바이올렛 보석 + 그린 글로우(유사도/타이머). 폰트 Cinzel / Noto Serif KR / Noto Sans KR / Orbitron. 토큰: `src/styles/tokens.css`.

## 확정 규칙
- 2라운드. 모든 참가자가 매 라운드 한 번씩 출제자.
- **참가 최대 10명** *(2026-11-26 갱신: 기존 6 → 10)*.
- **봉투 = 참가 인원 수만큼 준비** *(2026-11-26 갱신: 고정 6개 → 참가자 수. 남는 봉투 폐기 개념 없음)*.
- 봉투당 명사 5개(고유명사 제외). 각자 1개 봉투 선택 → 단어 5개는 본인만.
- 히든워드는 본인만, 서버 보관(공개 데이터에 미포함). 2라운드엔 남은 4개 중 다른 단어.
- 출제 순서 추첨. 차수당 힌트 15분·최대 10개. 유사도 95%↑ 시 힌트 즉시 종료(정답 처리 아님).
- 정답 제출 5분, 비공개. 전원 제출 or 5분 종료 시 공개. 정답=히든워드 정확 일치(정규화).
- 정답자 어느 차수든 1점. 무정답 시 출제자 최종 실패 차수에 따라 1/2/3점(누적 아님).
- 2라운드 점수 2배. 1위 피스 4개. 연맹 징표 없음.
- 유사도 = 의미적 거리 + 문맥적 공생 + 관계적 구조(독립 모듈, 가중치 가변).
